1. AI Office는 무엇인가요

내 컴퓨터 안에 작은 회사를 하나 차린다고 생각하면 됩니다.

  • 대표는 나입니다. 화면에 업무를 적으면 비서실장(AI)이 받아서 일을 나눕니다.
  • 마케팅부·문서제작부 같은 부서와 AI 직원을 내가 만들고, 직원들이 조사·문서 작성·검토를 나눠 합니다.
  • 진행 상황은 브라우저의 대시보드(관제 화면)에서 실시간으로 보입니다. 다 끝나면 결과 파일을 보여 줍니다.
  • 모든 것이 내 컴퓨터에서만 돌아갑니다. 인터넷에 따로 서버를 올리지 않습니다.
대표가 지시→ 비서실장이 분담→ 직원들이 작업→ 비서실장 검토→ 결과 전달
알아 두기이 가이드에서는 명령어를 외울 필요가 없습니다. 설치 때 딱 한 줄만 복사해서 붙여 넣고, 그다음부터는 터미널의 AI(Claude 또는 Codex)에게 말로 부탁하면 AI가 대신 처리합니다. 위쪽 쓸 AI에서 Claude나 Codex를 고르면 그에 맞는 설명만 보입니다.

2. 준비물

시작하기 전에 아래를 확인해 주세요.

  • 컴퓨터: 맥(macOS 13 이상) 또는 윈도우(10 이상). 인터넷 연결.
  • AI 유료 구독 계정 하나 이상: 비서실장과 직원들이 이 계정으로 일합니다. 둘 중 하나만 있어도 됩니다.
    • Claude (Pro 또는 Max): claude.ai에서 가입
    • Codex = ChatGPT 유료 구독 (Plus·Pro 등): chatgpt.com에서 가입
  • 둘 다 있으면 기본 설정 그대로 씁니다. 계획·실무는 Claude가, 최종 검토는 Codex가 맡습니다.
  • 컴퓨터 관리자 비밀번호: 프로그램을 설치할 때 물어볼 수 있습니다.
주의계정은 반드시 본인 것을 쓰세요. 한 사람의 계정을 여러 명이 같이 쓰면 사용량 한도가 금방 찹니다.

3. 처음 한 번만: 설치하기

위에서 내 컴퓨터 종류(맥/윈도우)를 먼저 고르면 그에 맞는 설명만 보입니다.

1

Node.js 설치하기

AI Office를 돌리는 데 필요한 기본 프로그램입니다.

  1. nodejs.org에 들어갑니다.
  2. 초록색 LTS라고 적힌 다운로드 버튼을 누릅니다.
  3. 받은 설치 파일을 열고 계속 / Next만 눌러 끝까지 설치합니다.
2

IntelliJ IDEA 설치하기

프로그램 파일을 받고, AI와 대화할 터미널(검은 글씨 창)을 여는 데 씁니다.

  1. IntelliJ IDEA 다운로드 페이지에 들어갑니다.
  2. 맥은 내 컴퓨터 칩에 맞는 파일을 고릅니다. 잘 모르면 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여에서 Apple M1·M2·M3…이면 Apple Silicon, Intel이면 Intel을 고릅니다.
  3. 무료로 쓸 수 있는 버전을 받아 설치합니다. 결제하지 않아도 됩니다.
  4. 받은 파일을 열고, IntelliJ 아이콘을 응용 프로그램(Applications) 폴더로 끌어다 놓습니다.
  5. 받은 설치 파일을 열고 Next를 눌러 끝까지 설치합니다.
  6. IntelliJ를 처음 켜면 약관 동의·설정 화면이 나옵니다. 기본값 그대로 넘어가면 됩니다.
3

AI Office 받기 (깃 클론)

인터넷에 있는 AI Office 프로그램을 내 컴퓨터로 복사해 오는 단계입니다.

  1. IntelliJ 첫 화면에서 Clone Repository를 누릅니다. (버전에 따라 Get from VCS 또는 저장소 복제로 보일 수 있습니다.)
  2. URL 칸에 아래 주소를 붙여 넣습니다.
    https://github.com/JISANGHYEOK-0901/ai-office.git
  3. Directory(저장할 위치)는 그대로 둬도 됩니다.
  4. Clone을 누릅니다.
  5. “Git이 없습니다”라는 안내가 나오면 Download and Install(다운로드 및 설치)을 누르고 기다립니다. 맥에서 “개발자 도구를 설치하겠습니까?” 창이 뜨면 설치를 누릅니다.
  6. “이 프로젝트를 신뢰하시겠습니까?” 창이 나오면 Trust Project(신뢰)를 누릅니다.
완료왼쪽에 ai-office 폴더와 파일 목록이 보이면 성공입니다.
4

터미널 열기

  1. IntelliJ 화면 왼쪽 아래의 터미널 아이콘(>_ 모양)을 누릅니다.
    또는 단축키 ⌥ Option + F12Alt + F12를 누릅니다.
  2. 아래쪽에 글자를 입력할 수 있는 창이 열립니다. 이 창을 터미널이라고 부릅니다.
팁메뉴에서 찾으려면 View(보기) → Tool Windows(도구 창) → Terminal(터미널)입니다.
5

Claude 설치하기 (복사·붙여넣기 한 번)

아래 한 줄을 복사해서 터미널에 붙여 넣고 Enter를 누릅니다. 설치가 끝날 때까지 1~2분 기다립니다.

curl -fsSL https://claude.ai/install.sh | bash

붙여 넣기: ⌘ Command + V

irm https://claude.ai/install.ps1 | iex

붙여 넣기: Ctrl + V (안 되면 마우스 오른쪽 클릭)

  1. 설치가 끝나면 터미널 창 위쪽의 ＋ 버튼을 눌러 새 터미널을 엽니다. (또는 IntelliJ를 껐다 켭니다.)
팁설치 마지막에 “PATH에 추가하세요”처럼 영어 안내가 나오면, 그 안내 줄을 그대로 복사해 붙여 넣고 Enter를 누른 뒤 새 터미널을 엽니다.
5

Codex 설치하기 (복사·붙여넣기 한 번)

아래 한 줄을 복사해서 터미널에 붙여 넣고 Enter를 누릅니다. 설치가 끝날 때까지 1~2분 기다립니다.

npm install -g @openai/codex

붙여 넣기: ⌘ Command + V

붙여 넣기: Ctrl + V (안 되면 마우스 오른쪽 클릭)

  1. 설치가 끝나면 터미널 창 위쪽의 ＋ 버튼을 눌러 새 터미널을 엽니다. (또는 IntelliJ를 껐다 켭니다.)
팁“permission denied” 또는 “EACCES”라는 글자가 나오면 아래 줄을 대신 붙여 넣고, 맥 로그인 비밀번호를 입력한 뒤 Enter를 누릅니다. 비밀번호는 입력해도 화면에 보이지 않는 것이 정상입니다.
sudo npm install -g @openai/codex
6

Claude 실행하고 로그인하기

  1. 터미널에 claude라고 입력하고 Enter를 누릅니다.
    claude
  2. 화면 색 고르기가 나오면 방향키로 고르고 Enter.
  3. 로그인 방법은 Claude 구독 계정(Claude account with subscription)을 고릅니다.
  4. 브라우저가 열리면 내 Claude 계정으로 로그인하고 승인(Authorize)을 누릅니다. 다시 IntelliJ로 돌아옵니다.
  5. “이 폴더의 파일을 신뢰하나요?”라고 물으면 Yes, proceed를 고릅니다.
완료입력창(>)이 보이면 이제 Claude와 대화할 수 있습니다. 여기서부터는 명령어 대신 한국어로 말하면 됩니다.
6

Codex 실행하고 로그인하기

  1. 터미널에 codex라고 입력하고 Enter를 누릅니다.
    codex
  2. 로그인 방법은 ChatGPT로 로그인(Sign in with ChatGPT)을 고릅니다.
  3. 브라우저가 열리면 내 ChatGPT 계정으로 로그인하고 허용합니다. 다시 IntelliJ로 돌아옵니다.
  4. “이 폴더를 신뢰하나요?”처럼 물으면 Yes(신뢰)를 고릅니다.
완료입력창이 보이면 이제 Codex와 대화할 수 있습니다. 여기서부터는 명령어 대신 한국어로 말하면 됩니다.
둘 다 쓰고 싶다면위쪽 쓸 AI를 바꿔 5~6단계를 한 번 더 하면 됩니다. 또는 먼저 설치한 AI에게 “Codex도 설치해줘”(또는 “Claude도 설치해줘”)라고 부탁합니다. 로그인은 브라우저 창이 뜨면 직접 해 주세요.

4. 서버 켜기

“서버”는 AI Office 대시보드를 내 컴퓨터에서 돌아가게 하는 것입니다.

Claude 또는 Codex 입력창에 이렇게 적고 Enter를 누릅니다.

AI Office 서버 켜줘
  • 처음에는 AI가 필요한 부품을 설치하고 환경을 점검합니다. 몇 분 걸릴 수 있습니다.
  • 중간에 “이 작업을 실행해도 될까요?”(Claude: Do you want to proceed? / Codex: Allow command?)라고 물으면, 설명을 읽고 Yes를 고릅니다.
  • 끝나면 브라우저에 대시보드가 열립니다. 직접 열려면 주소창에 http://127.0.0.1:4777 을 입력합니다.
알아 두기서버는 한 번 켜면 IntelliJ나 터미널 창을 닫아도 계속 켜져 있습니다. 다 쓰면 AI에게 “서버 꺼줘”라고 말해 끕니다. 컴퓨터를 껐다 켜면 서버도 꺼지니 다시 “서버 켜줘”라고 하면 됩니다.

5. 사용 전 세팅: AI에게 맡기기

부서와 직원을 하나하나 만들지 않아도 됩니다. IntelliJ 터미널의 Claude 또는 Codex에게 내 업무를 설명하면 알맞게 만들어 줍니다.

이렇게 말해 보세요

블로그 콘텐츠 마케팅 업무를 맡길 건데 알맞게 부서와 팀원들을 세팅해줘
우리 가게 온라인 주문·재고 정리랑 매출 보고서를 맡길 거야. 필요한 부서랑 직원을 만들어줘
경쟁사 조사하고 제안서 쓰는 일을 자주 해. 리서치부랑 문서제작부를 만들고 팀장도 정해줘
매일 유튜브 영상 보고 카페 글 올리는 일을 맡길 거야. 맡을 사람들을 세팅해줘
  • AI가 먼저 어떤 부서에 누구를 둘지 표로 보여 주고 물어봅니다. 괜찮으면 “좋아, 진행해”, 바꾸고 싶으면 “SNS 담당은 빼줘”처럼 답합니다. 일일이 확인하기 귀찮으면 처음부터 “알아서 해줘”를 붙이면 됩니다.
  • 세팅이 끝나면 대시보드에 바로 나타납니다. 새로고침하지 않아도 됩니다.
  • 기존 부서·직원은 그대로 두고 필요한 것만 더합니다. 바꾸기 전 구성은 따로 저장해 두니 “방금 세팅 되돌려줘”라고 하면 원래대로 돌아갑니다.

세팅을 다듬을 때

마케팅부에 블로그 글 검수 담당을 한 명 더 추가해줘
모든 직원이 존댓말로 쓰고, 출처를 꼭 적게 회사 규칙을 정해줘
리서치부 직원은 빠르고 저렴한 모델로 바꿔줘
지금 우리 회사 부서랑 직원 구성 설명해줘
다음 단계세팅이 끝나면 대시보드 위쪽 비서실장 입력창에 실제 업무를 적습니다. 예: “다음 달 블로그 콘텐츠 주제와 발행 일정을 기획해줘”

6. 대시보드 사용법

처음에는 회사가 비어 있습니다. 부서와 직원부터 만듭니다.

1

부서 만들기

  • 5. 사용 전 세팅처럼 AI에게 맡겼다면 이 단계와 다음 단계는 건너뛰어도 됩니다. 화면에서 직접 만들고 싶을 때 아래처럼 합니다.
  • 처음 화면의 첫 부서 만들기 카드나 + 부서 추가를 누릅니다.
  • 마케팅·리서치·운영·재무처럼 미리 만들어 둔 부서(프리셋)를 고르면 편합니다. 인원까지 추가를 누르면 직원도 한 번에 채워집니다.
  • Codex만 쓴다면 부서를 만들 때 엔진을 Codex로, 역할을 실행으로 고릅니다.
2

직원 추가하기

  • 부서 카드의 + 직원 추가를 누르고 이름(예: 김대리), 직급, 담당 업무를 정합니다.
  • 직원마다 근무 / 휴무를 바꿀 수 있습니다. 휴무인 직원은 일을 받지 않습니다.
3

업무 지시하기

  • 화면 위쪽 비서실장 입력창에 하고 싶은 일을 평소 말투로 적고 지시하기를 누릅니다.
  • 예: “경쟁사 3곳 가격 정책 조사해서 보고서로 정리해 줘”, “마케팅부가 조사하고 문서제작부가 HTML로 만들어 줘”
  • 담당을 적지 않으면 비서실장이 관련 부서와 회의를 열어 알아서 나눕니다.
  • 입력창 옆의 Codex / Claude 선택은 최종 검토를 누가 할지 정합니다. Claude만 쓴다면 Claude로 바꿔 주세요. Codex만 쓴다면 그대로 Codex에 둡니다. Claude가 없으면 계획·실무·검토를 모두 Codex가 맡습니다.
4

진행 보기와 답하기

  • 관제 탭: 부서별 진행 상황, 사무실 탭: 직원들이 움직이는 모습, 오른쪽 실시간 피드: 누가 무엇을 하는지.
  • AI가 물어볼 것이 있으면 “답변 필요” 표시가 뜹니다. 눌러서 답을 적고 보내기. 잘 모르겠으면 “기본값으로 진행”이라고만 써도 됩니다.
  • 업무가 끝나면 완료 창에 결과 파일이 나옵니다. HTML 파일은 새 탭에서 열기로 봅니다. 지난 결과는 산출물 탭에 모여 있습니다.
5

그 밖에 자주 쓰는 기능

  • 회사 설정: 모든 직원이 지킬 회사 규칙, 회사 구성 내보내기(백업)·가져오기.
  • 반복 예약: “매일 오전 11시에 이 업무 하기”처럼 정해진 시간에 자동으로 일을 시킵니다. 컴퓨터와 서버가 켜져 있어야 실행됩니다.
  • 계정 연결: 메일 발송·카페 글 게시처럼 바깥 사이트에서 할 일이 있을 때 내 계정을 연결합니다. 비밀번호는 연결 창에만 입력합니다.
  • 내역 초기화: 끝난 업무·실행 기록을 정리합니다. 결과 파일과 계정은 지워지지 않습니다.

7. 내 마음대로 고쳐 쓰기

AI Office는 쓰면서 내 일에 맞게 계속 바꿔 나가는 프로그램입니다.

화면에서 바로 바꾸기

  • 부서·직원 추가, 수정, 삭제
  • 직원 담당 업무와 상세 지침
  • 직원마다 쓸 AI 모델
  • 회사 공통 규칙, 반복 예약

AI에게 말로 바꾸기

  • 화면 모양, 버튼, 색깔
  • 새 기능 추가
  • 불편한 동작 고치기
  • 사용법 질문

IntelliJ 터미널의 Claude 또는 Codex에게 이렇게 말해 보세요.

대시보드 실시간 피드 글씨를 더 크게 바꿔줘
완료된 업무를 엑셀 파일로 내려받는 버튼을 만들어줘
방금 고친 거 잘 되는지 확인하고 서버 다시 켜줘
반복 예약은 어떻게 쓰는 거야?
  • 한 번에 하나씩 부탁하면 결과가 더 정확합니다.
  • 고친 뒤 마음에 안 들면 “방금 바꾼 거 되돌려줘”라고 하면 됩니다.
  • AI가 고친 뒤 스스로 검사(테스트)를 돌려 확인합니다.

8. 매일 쓰는 순서

IntelliJ 열기→ 터미널 열기→ claudecodex 입력→ “서버 켜줘”→ 브라우저에서 업무 지시
  • 다 쓰면 AI에게 “서버 꺼줘”라고 말합니다. 창만 닫으면 서버는 계속 켜져 있습니다.
  • 새 버전이 나왔다고 들으면 이렇게 부탁합니다.
AI Office 최신 버전으로 업데이트해줘. 내가 고친 부분은 유지해줘

9. 꼭 지켜 주세요

  • 비밀번호·카드번호·인증번호를 AI 대화창이나 업무 지시에 적지 마세요. 바깥 사이트 계정은 계정 연결 창에서만 로그인합니다.
  • 메일 발송·글 게시처럼 밖으로 나가는 일은 내가 지시한 경우에만 실행됩니다. 지시하지 않으면 초안까지만 만듭니다. 송금·결제·세금 신고·계약은 AI가 하지 않습니다.
  • AI가 만든 숫자와 사실은 중요한 곳에 쓰기 전에 꼭 원본과 확인하세요. 결과 보고서의 “확인 필요” 항목을 먼저 봅니다.
  • 모든 작업은 내 Claude·ChatGPT 계정 사용량을 씁니다. 큰 업무를 한꺼번에 많이 맡기면 한도가 빨리 찰 수 있습니다.
  • 회사 데이터(부서·직원·결과 파일)는 내 컴퓨터의 AIOffice 폴더에 있습니다. 컴퓨터를 바꾸기 전에는 회사 설정 → 회사 구성 내보내기로 백업하세요.

10. 막혔을 때

대부분은 터미널의 AI에게 화면에 보이는 그대로 말하면 해결됩니다.

claude나 codex를 입력했더니 “찾을 수 없다(command not found)”고 나와요

터미널 창 위의 ＋로 새 터미널을 열거나 IntelliJ를 껐다 켠 뒤 다시 입력합니다. 그래도 안 되면 3-5단계의 설치 줄을 한 번 더 붙여 넣습니다.

AI가 자꾸 “실행해도 될까요?”라고 물어봐요

AI가 내 컴퓨터에서 무언가를 실행하기 전에 허락을 받는 정상 동작입니다. 설명을 읽고 괜찮으면 Yes를 고릅니다. 모르겠으면 “이거 뭐 하는 거야?”라고 물어보세요.

브라우저에 대시보드가 안 열려요

주소창에 http://127.0.0.1:4777 을 직접 입력합니다. 그래도 안 되면 AI에게 “서버 상태 확인해줘”라고 말합니다.

화면 위에 “Claude/Codex가 설치되지 않았습니다”라고 떠요

둘 중 하나만 쓰기로 했다면 안 쓰는 쪽 안내는 무시해도 됩니다. Claude만 쓰면 상단 검토 선택을 Claude로 바꿉니다. Codex만 쓰면 Codex가 계획·실무·검토를 모두 맡습니다. 나중에 다른 쪽도 쓰고 싶으면 AI에게 “Codex도 설치해줘”(또는 “Claude도 설치해줘”)라고 말합니다.

업무가 멈춘 것 같아요

오른쪽 업무 · 실행 목록에서 상태를 봅니다. “답변 필요”라면 답을 적어 주세요. 멈췄다면 그 실행을 중지한 뒤 대화창에 “이어서 재개”라고 답하면 끝난 단계는 건너뛰고 이어서 합니다.

“사용량 한도에 도달했습니다”라고 나와요

내 Claude 또는 ChatGPT 구독의 사용량을 다 쓴 상태입니다. 안내된 시간이 지나면 다시 쓸 수 있습니다. 둘 다 있다면 다른 쪽 AI로 바꿔 써도 됩니다.

그 밖의 문제

화면에 나온 오류 문장을 그대로 복사해서 AI에게 붙여 넣고 “이거 해결해줘”라고 말합니다.

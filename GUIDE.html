1. AI Office는 무엇인가요

내 컴퓨터 안에 작은 회사를 하나 차린다고 생각하면 됩니다.

  • 대표는 나입니다. 화면에 업무를 적으면 비서실장(AI)이 받아서 일을 나눕니다.
  • 마케팅부·문서제작부 같은 부서와 AI 직원을 내가 만들고, 직원들이 조사·문서 작성·검토를 나눠 합니다.
  • 진행 상황은 브라우저의 대시보드(관제 화면)에서 실시간으로 보입니다. 다 끝나면 결과 파일을 보여 줍니다.
  • 모든 것이 내 컴퓨터에서만 돌아갑니다. 인터넷에 따로 서버를 올리지 않습니다.
대표가 지시→ 비서실장이 분담→ 직원들이 작업→ 비서실장 검토→ 결과 전달
알아 두기이 가이드에서는 명령어를 외울 필요가 없습니다. 설치 때 두 줄(AI 설치·Node 설치)만 복사해서 붙여 넣고, 그다음부터는 터미널의 AI(Claude 또는 Codex)에게 말로 부탁하면 AI가 대신 처리합니다. 위쪽 쓸 AI에서 Claude나 Codex를 고르면 그에 맞는 설명만 보입니다.

2. 준비물

시작하기 전에 아래를 확인해 주세요.

  • 컴퓨터: 맥(macOS 13 이상) 또는 윈도우(10 이상). 인터넷 연결.
  • AI 유료 구독 계정 하나 이상: 비서실장과 직원들이 이 계정으로 일합니다. 둘 중 하나만 있어도 됩니다.
    • Claude (Pro 또는 Max): claude.ai에서 가입
    • Codex = ChatGPT 유료 구독 (Plus·Pro 등): chatgpt.com에서 가입
  • 둘 다 있으면 기본 설정 그대로 씁니다. 계획·실무는 Claude가, 최종 검토는 Codex가 맡습니다.
  • 컴퓨터 관리자 비밀번호: 프로그램을 설치할 때 물어볼 수 있습니다.
주의계정은 반드시 본인 것을 쓰세요. 한 사람의 계정을 여러 명이 같이 쓰면 사용량 한도가 금방 찹니다.

3. 처음 한 번만: 설치하기

직접 붙여 넣는 명령은 AI 설치 한 줄과 Node 설치 한 줄뿐입니다. AI Office를 받고 설정하는 일은 AI에게 말로 맡깁니다. 위에서 내 컴퓨터 종류(맥/윈도우)와 쓸 AI를 먼저 고르면 맞는 설명만 보입니다.

1

터미널 열기

AI와 글자로 대화하는 창입니다.

  1. ⌘ Command + Space를 누르고 터미널(Terminal)이라고 입력한 뒤 Enter를 누릅니다.
  2. 흰색 또는 검은색 글자 창이 열리면 됩니다.
  1. 화면 아래 시작 버튼을 누르고 PowerShell이라고 입력합니다.
  2. Windows PowerShell을 누릅니다. (관리자 권한으로 열 필요는 없습니다.)
팁IntelliJ·VS Code를 쓰고 있다면 그 안의 터미널을 써도 됩니다(IntelliJ: ⌥ Option + F12Alt + F12).
2

Claude 설치하기 (복사·붙여넣기 한 번)

아래 한 줄을 복사해서 터미널에 붙여 넣고 Enter를 누릅니다. 1~2분 기다립니다. Node 같은 다른 프로그램은 필요 없습니다.

curl -fsSL https://claude.ai/install.sh | bash

붙여 넣기: ⌘ Command + V

irm https://claude.ai/install.ps1 | iex

붙여 넣기: Ctrl + V (안 되면 마우스 오른쪽 클릭)

“스크립트를 실행할 수 없습니다”라는 빨간 글자가 나오면 아래 줄을 대신 붙여 넣습니다.

powershell -ExecutionPolicy ByPass -c "irm https://claude.ai/install.ps1 | iex"
  1. 설치가 끝나면 터미널 창을 닫고 새로 엽니다(1단계).
  2. 설치됐는지 보려면 claude --version을 입력합니다. 버전 숫자가 나오면 성공입니다.
팁설치 마지막에 “PATH에 추가하세요”처럼 영어 안내가 나오면, 그 안내 줄을 그대로 복사해 붙여 넣고 Enter를 누른 뒤 새 터미널을 엽니다.
2

Codex 설치하기 (복사·붙여넣기 한 번)

아래 한 줄을 복사해서 터미널에 붙여 넣고 Enter를 누릅니다. 1~2분 기다립니다. Node 같은 다른 프로그램은 필요 없습니다.

curl -fsSL https://chatgpt.com/codex/install.sh | sh

붙여 넣기: ⌘ Command + V

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

붙여 넣기: Ctrl + V (안 되면 마우스 오른쪽 클릭)

  1. 설치가 끝나면 터미널 창을 닫고 새로 엽니다(1단계).
  2. 설치됐는지 보려면 codex --version을 입력합니다. 버전 숫자가 나오면 성공입니다.
Node가 이미 있어서 npm으로 설치하고 싶다면
npm install -g @openai/codex

“permission denied”·“EACCES”가 나오면 sudo npm install -g @openai/codex로 다시 하고 맥 로그인 비밀번호를 입력합니다(입력해도 화면에 안 보이는 게 정상).

3

Node 설치하기 (복사·붙여넣기 한 번)

AI Office를 돌리는 기본 프로그램입니다. Node 20 이상이 필요하고, 아래 명령은 지금의 안정 버전(LTS)을 설치합니다.

touch ~/.zshrc && curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash && \. "$HOME/.nvm/nvm.sh" && nvm install --lts

Node 공식 사이트가 권장하는 nvm 방식입니다. 맥 비밀번호를 묻지 않습니다.

winget install OpenJS.NodeJS.LTS

약관 동의(Y/N)를 물으면 Y, “이 앱이 디바이스를 변경하도록 허용하시겠어요?” 창이 뜨면 예를 누릅니다.

  1. 설치가 끝나면 터미널 창을 닫고 새로 엽니다.
  2. node --version을 입력해 v20 이상(예: v26.x)이 나오면 성공입니다.
명령이 안 될 때: 설치 파일로 설치하기

nodejs.org 다운로드에서 LTS 설치 파일(.pkg.msi)을 받아 열고 계속/Next로 끝까지 설치합니다. 또는 4단계 뒤 AI에게 “Node 설치해줘”라고 부탁해도 됩니다.

4

Claude 실행하고 로그인하기

  1. 터미널에 claude라고 입력하고 Enter를 누릅니다.
    claude
  2. 화면 색 고르기가 나오면 방향키로 고르고 Enter.
  3. 로그인 방법은 Claude 구독 계정(Claude account with subscription)을 고릅니다.
  4. 브라우저가 열리면 내 Claude 계정으로 로그인하고 승인(Authorize)을 누릅니다. 다시 터미널로 돌아옵니다.
  5. “이 폴더의 파일을 신뢰하나요?”라고 물으면 Yes, proceed를 고릅니다.
완료입력창(>)이 보이면 이제 Claude와 대화할 수 있습니다. 여기서부터는 명령어 대신 한국어로 말하면 됩니다.
4

Codex 실행하고 로그인하기

  1. 터미널에 codex라고 입력하고 Enter를 누릅니다.
    codex
  2. 로그인 방법은 ChatGPT로 로그인(Sign in with ChatGPT)을 고릅니다.
  3. 브라우저가 열리면 내 ChatGPT 계정으로 로그인하고 허용합니다. 다시 터미널로 돌아옵니다.
  4. “이 폴더를 신뢰하나요?”처럼 물으면 Yes(신뢰)를 고릅니다.
완료입력창이 보이면 이제 Codex와 대화할 수 있습니다. 여기서부터는 명령어 대신 한국어로 말하면 됩니다.
5

AI에게 설치를 맡기기

AI 입력창에 아래 문장을 그대로 보냅니다.

https://github.com/JISANGHYEOK-0901/ai-office 를 내 홈 폴더에 받아서, README와 AGENTS.md 안내대로 AI Office 쓸 수 있게 환경설정하고 서버 켜줘
  • AI가 프로그램 받기(깃 클론), Node 버전 확인, 필요한 부품 설치, 브라우저 업무용 Chrome 준비, 설치 점검, 서버 켜기까지 이어서 합니다. 몇 분 걸릴 수 있습니다.
  • 중간에 “이 작업을 실행해도 될까요?”(Claude: Do you want to proceed? / Codex: Allow command?)라고 물으면, 설명을 읽고 Yes를 고릅니다.
  • 이것만은 직접 합니다: “개발자 도구를 설치하겠습니까?” 창이 뜨면 설치를 누르고, 맥 비밀번호를 물으면 직접 입력합니다(입력해도 화면에 안 보이는 게 정상).“이 앱이 디바이스를 변경하도록 허용하시겠어요?” 창이 뜨면 예를 누릅니다. AI는 비밀번호를 대신 넣을 수 없습니다.
완료브라우저에 AI Office 대시보드(http://127.0.0.1:4777)가 열리면 설치가 끝났습니다.
6

다음부터는 AI Office 폴더에서 시작하기

AI가 AI Office 사용 규칙을 읽도록, 다음부터는 터미널에서 AI Office 폴더로 들어간 뒤 AI를 실행합니다.

cd ~/ai-office
claude
codex

지금 대화 중인 AI에게 “AI Office 폴더에서 다시 시작하는 방법 알려줘”라고 물어도 됩니다. 다른 곳에 받았다면 그 폴더로 cd 합니다(예: IntelliJ로 받았으면 ~/IdeaProjects/ai-office).

둘 다 쓰고 싶다면위쪽 쓸 AI를 바꿔 2·4단계를 한 번 더 하면 됩니다. 또는 먼저 설치한 AI에게 “Codex도 설치해줘”(또는 “Claude도 설치해줘”)라고 부탁합니다. 로그인은 브라우저 창이 뜨면 직접 해 주세요.
AI 없이 직접 설치하고 싶을 때 (IntelliJ로 받기)
  1. nodejs.org에서 초록색 LTS 버튼으로 Node.js를 받아 설치합니다.
  2. IntelliJ IDEA 무료 버전을 받아 설치합니다. 맥은 칩(Apple Silicon/Intel)에 맞는 파일을 고릅니다(사과 메뉴 → 이 Mac에 관하여).
  3. IntelliJ 첫 화면에서 Clone Repository(또는 Get from VCS)를 누르고 URL에 아래 주소를 넣은 뒤 Clone. “Git이 없습니다”가 나오면 Download and Install, “프로젝트를 신뢰하시겠습니까?”에는 Trust Project.
    https://github.com/JISANGHYEOK-0901/ai-office.git
  4. IntelliJ 왼쪽 아래 터미널 아이콘(>_)으로 터미널을 열고 2·4단계(AI 설치·로그인)를 한 뒤 4. 서버 켜기로 넘어갑니다.

4. 서버 켜기

“서버”는 AI Office 대시보드를 내 컴퓨터에서 돌아가게 하는 것입니다.

Claude 또는 Codex 입력창에 이렇게 적고 Enter를 누릅니다.

AI Office 서버 켜줘
  • 처음에는 AI가 필요한 부품을 설치하고 환경을 점검합니다. 몇 분 걸릴 수 있습니다.
  • 중간에 “이 작업을 실행해도 될까요?”(Claude: Do you want to proceed? / Codex: Allow command?)라고 물으면, 설명을 읽고 Yes를 고릅니다.

5. 어디에 무엇을 요청할까: 처음부터 권장 순서

기본은 터미널의 AI에게 그냥 말하기입니다. 프로그램 일은 터미널 AI가 바로 하고, 실제 회사 업무는 터미널 AI가 대시보드 비서실장에게 넘겨서 처리합니다.

터미널의 AI (Claude)(Codex)

AI Office 폴더에서 터미널로 실행한 AI입니다(3-6단계). 여기에 다 말하면 됩니다.

  • 바로 하는 일: 서버 켜기·끄기, 설치 점검, 부서·직원 세팅, 화면·기능 고치기, 사용법 질문
  • 넘기는 일: 실제 업무를 비서실장에게 넣고, 비서실장 질문을 나에게 보여 주고, 내 답과 결과를 전해 줍니다

대시보드의 비서실장

실제 업무를 맡아 직원에게 나누고 검토합니다. 위쪽 비서실장 입력창에 직접 써도 됩니다.

  • 조사·보고서 작성, 파워포인트·워드·엑셀·HTML 만들기와 고치기
  • 카페·블로그 글, 댓글, 제휴 메일 보내기
  • 매일·정한 시간 예약 업무, 계속 지켜보기
  • 회사 사이트(ERP·관리자 화면) 조회·업로드
어디로 넣어도 같아요터미널 AI가 넣은 업무와 지시창에 쓴 업무는 같은 입구로 들어가 똑같이 처리됩니다. “실행할까요?”, 메일 20통 확인, 첨부 확인, 비서실장 검토가 모두 그대로 동작하고, 진행 상황과 결과는 대시보드에도 남습니다. 답은 터미널에서 해도, 대시보드 답변 필요에서 해도 같은 업무로 이어집니다.
내가 한 말 그대로터미널 AI는 내 말을 그대로 비서실장에게 넘기고, 넣기 전에 “넣을 지시”를 한 줄로 보여 줍니다. “보내줘”·“올려줘”·“끝까지 자동으로”·첨부 파일 이름·“매일 9시에”처럼 실제 실행을 허락하는 말은 내가 직접 해야 들어갑니다. AI가 알아서 덧붙이지 않습니다.
1

터미널 AI 실행 → 서버 켜기

AI Office 서버 켜줘
처음 설치가 잘 됐는지 점검해줘
2

맡길 업무에 맞게 직원 세팅

제휴처 조사하고 제휴 메일 보내는 업무를 맡길 건데 알맞게 부서와 직원 세팅해줘

자세한 방법은 6. 사용 전 세팅을 보세요.

3

대시보드 → 계정 연결 (밖으로 나가는 일이 있을 때만)

메일·카페 글·댓글·회사 사이트 작업을 시킬 거라면 대시보드 계정 연결에서 계정을 추가하고 로그인 창 열기로 처음 한 번 직접 로그인합니다. 이것만은 화면에서 직접 해야 합니다. 비밀번호는 AI에게 말하지 않습니다.

좋은 지시문 쓰는 법

필요한 것만 골라 한두 문장으로 씁니다.

  • 무엇을·얼마나: 목표와 수량 (업체 10곳, 글 2개)
  • 어디서·누구에게: 조사 범위, 카페·게시판 주소, 사이트 링크, 받는 곳
  • 누가 (선택): 담당 부서·직원. 비우면 비서실장이 정합니다
  • 어떻게 받을지 (선택): 엑셀·HTML·표, 저장할 폴더 전체 경로
  • 밖으로 나가는지: 보내기·올리기까지 할지, “초안만”인지. 확인 없이 끝까지 하려면 “끝까지 자동으로”
  • 언제: 지금 / “내일 오전 10시에” / “매일 오전 9시에” / “새 글이 올라오면 계속”
  • 한 지시에 한 가지 목표만 담으면 결과가 정확합니다. 큰 일은 나눠서 지시하세요.
  • 비밀번호·카드번호·인증번호는 지시문에 쓰지 않습니다.

6. 사용 전 세팅: AI에게 맡기기

부서와 직원을 하나하나 만들지 않아도 됩니다. 터미널의 Claude 또는 Codex에게 내 업무를 설명하면 알맞게 만들어 줍니다.

이렇게 말해 보세요

블로그 콘텐츠 마케팅 업무를 맡길 건데 알맞게 부서와 팀원들을 세팅해줘
우리 가게 온라인 주문·재고 정리랑 매출 보고서를 맡길 거야. 필요한 부서랑 직원을 만들어줘
경쟁사 조사하고 제안서 쓰는 일을 자주 해. 리서치부랑 문서제작부를 만들고 팀장도 정해줘
매일 유튜브 영상 보고 카페 글 올리는 일을 맡길 거야. 맡을 사람들을 세팅해줘
  • AI가 먼저 어떤 부서에 누구를 둘지 표로 보여 주고 물어봅니다. 괜찮으면 “좋아, 진행해”, 바꾸고 싶으면 “SNS 담당은 빼줘”처럼 답합니다. 일일이 확인하기 귀찮으면 처음부터 “알아서 해줘”를 붙이면 됩니다.
  • 세팅이 끝나면 대시보드에 바로 나타납니다. 새로고침하지 않아도 됩니다.
  • 기존 부서·직원은 그대로 두고 필요한 것만 더합니다. 바꾸기 전 구성은 따로 저장해 두니 “방금 세팅 되돌려줘”라고 하면 원래대로 돌아갑니다.

세팅을 다듬을 때

마케팅부에 블로그 글 검수 담당을 한 명 더 추가해줘
모든 직원이 존댓말로 쓰고, 출처를 꼭 적게 회사 규칙을 정해줘
리서치부 직원은 빠르고 저렴한 모델로 바꿔줘
지금 우리 회사 부서랑 직원 구성 설명해줘
다음 단계세팅이 끝나면 같은 터미널 AI에게 실제 업무를 말합니다(대시보드 위쪽 비서실장 입력창에 써도 됩니다). 예: “다음 달 블로그 콘텐츠 주제와 발행 일정을 기획해줘”

7. 대시보드 사용법

처음에는 회사가 비어 있습니다. 부서와 직원부터 만듭니다.

1

부서 만들기

  • 6. 사용 전 세팅처럼 AI에게 맡겼다면 이 단계와 다음 단계는 건너뛰어도 됩니다. 화면에서 직접 만들고 싶을 때 아래처럼 합니다.
  • 처음 화면의 첫 부서 만들기 카드나 + 부서 추가를 누릅니다.
  • 마케팅·리서치·운영·재무처럼 미리 만들어 둔 부서(프리셋)를 고르면 편합니다. 인원까지 추가를 누르면 직원도 한 번에 채워집니다.
  • Codex만 쓴다면 부서를 만들 때 엔진을 Codex로, 역할을 실행으로 고릅니다.
2

직원 추가하기

  • 부서 카드의 + 직원 추가를 누르고 이름(예: 김대리), 직급, 담당 업무를 정합니다.
  • 직원마다 근무 / 휴무를 바꿀 수 있습니다. 휴무인 직원은 일을 받지 않습니다.
3

업무 지시하기

  • 화면 위쪽 비서실장 입력창에 하고 싶은 일을 평소 말투로 적고 지시하기를 누릅니다. 터미널 AI에게 말해도 똑같이 처리됩니다(5. 어디에 무엇을 요청할까).
  • 예: “경쟁사 3곳 가격 정책 조사해서 보고서로 정리해 줘”, “마케팅부가 조사하고 문서제작부가 HTML로 만들어 줘”
  • 파일과 함께 지시하기: 입력창 옆 📎 파일을 누르거나 파일을 입력창에 끌어다 놓고, 할 일을 한 줄 적어 지시합니다(예: 상담사 워드를 올리고 “프로필 작성해 줘”). 파일은 보관함/업로드/날짜/에 저장되고, 비서실장이 문서 앞부분을 미리 읽어(연락처는 가림) 맞는 부서와 결과 파일 이름을 정합니다. 한 번에 10개, 파일마다 25MB까지 문서·한글·그림 파일을 올릴 수 있습니다.
  • 결과 파일 바로 받기: 업무가 끝나면 비서실장 대화 창 맨 아래 “결과 파일” 칸에서 내려받기(여러 개면 모두 내려받기)를 누르세요. 완료 창과 산출물 탭에도 파일마다 내려받기 버튼이 있어 폴더를 찾아 들어갈 필요가 없습니다.
  • 단순한 자료 찾기는 빠른 조회로 직원 한 명이 1분 안팎으로 끝냅니다(최종 검토 생략, 보고서에 표시). 결과는 md와 HTML로 함께 받습니다. 파일 하나의 작은 수정(“보관함/표.xlsx에 합계 행 추가해줘”)도 같은 방식으로 빠르게 끝내고, 바뀐 곳을 보고서에 적습니다. 원본은 그대로 두고 새 파일로 저장합니다. 정확도가 중요하면 지시에 “검증해서”나 “보고서로”를 적어 주세요. 계획·검토까지 거치는 전체 절차로 처리합니다.
  • 업무가 진행 중일 때 “아 참고로 …”처럼 덧붙이면 새 업무를 만들지 않고 그 업무에 전달합니다. 다음 단계부터 반영됩니다.
  • 담당을 적지 않으면 비서실장이 맞는 부서에 맡깁니다. 여러 부서가 함께 해야 하고 나누기 어려운 일만 회의를 엽니다.
  • 일하는 중에도 비서실장이 결과를 보며 단계를 더하거나 고칩니다. 마지막에 검토해 부족한 부분은 담당에게 다시 맡깁니다.
  • 결과 파일 저장 위치를 정하고 싶으면 지시에 전체 경로를 적습니다(예: “~/Desktop/상담사 리스트 폴더에 저장해줘”). 적지 않으면 보관함/최종산출물/날짜 폴더에 모입니다.
  • 메일 발송·카페 글·댓글처럼 밖으로 나가는 일은 올리기 직전에 한 번 “실행할까요?”라고 묻습니다. 확인 없이 끝까지 하려면 지시에 “끝까지 자동으로”를 적어 주세요.
  • 메일은 한 번에 20통까지만 보내고, 지시문에 적은 파일을 첨부할 수 있습니다. 자세한 방법은 8. 제휴 메일 보내기를 보세요.
  • 입력창 옆의 Codex / Claude 선택은 최종 검토를 누가 할지 정합니다. 고르는 법은 아래 6번을 보세요. Claude만 쓴다면 Claude로 바꿔 주세요. Codex만 쓴다면 그대로 Codex에 둡니다. Claude가 없으면 계획·실무·검토를 모두 Codex가 맡습니다.
4

진행 보기와 답하기

  • 관제 탭: 부서별 진행 상황, 사무실 탭: 직원들이 움직이는 모습, 오른쪽 실시간 피드: 누가 무엇을 하는지.
  • AI가 물어볼 것이 있으면 “답변 필요” 표시가 뜹니다. 눌러서 답을 적고 보내기. 잘 모르겠으면 “기본값으로 진행”이라고만 써도 됩니다.
  • 업무가 끝나면 완료 창에 결과 파일이 나옵니다. HTML 파일은 새 탭에서 열기로 봅니다. 지난 결과는 산출물 탭에 모여 있습니다.
5

그 밖에 자주 쓰는 기능

  • 회사 설정: 모든 직원이 지킬 회사 규칙, 결과 파일 저장 위치, 업무 예산(업무 하나가 쓸 AI 사용 횟수·시간, 기본 40회·60분), 회사 구성 내보내기(백업)·가져오기. 업무가 예산의 80%를 쓰면 계속할지 묻습니다.
  • 예약: “내일 오전 10시에 이 업무 하기”(한 번), “내일부터 3일간 매일 9시에”(정한 횟수), “매일 오전 11시에”(매일)처럼 정해진 시간에 자동으로 일을 시킵니다. 지시창에 그렇게 써도 예약됩니다. 컴퓨터와 서버가 켜져 있어야 실행됩니다.
  • 계정 연결: 메일 발송·카페 글 게시처럼 바깥 사이트에서 할 일이 있을 때 내 계정을 연결합니다. 연결이 없으면 업무 중에 로그인 창이 저절로 열립니다. 창에서 로그인만 하면 답장 없이 이어 갑니다. 지시에 카페·블로그 주소가 있으면 일을 시작하기 전에 실제로 로그인돼 있는지 먼저 열어 보고, 풀렸으면 바로 로그인 창을 엽니다. 로그인 창은 30분 기다립니다. 미리 해 두려면 이 메뉴를 씁니다. 자동 게시는 네이버 등에서 계정 보호 조치를 부를 수 있으니 개인 계정 대신 업무 전용 계정을 권장합니다. 보호 조치가 걸리면 자동 작업을 멈추며, 서비스 공식 화면에서 직접 해제해야 합니다. 글·댓글 사이 간격은 회사 설정에서 바꿀 수 있습니다(기본 30초). 네이버 카페 글은 네이버 계정의 카페 공식 API 연결을 해 두면 브라우저 대신 공식 API로 올라가 로그인 보호 조치를 줄일 수 있습니다(네이버 지도 링크가 든 장소 글은 장소 카드를 만들려고 브라우저로 올립니다)(보관함/계정.env에 NAVER_API_CLIENT·NAVER_API_SECRET·NAVER_API_CALLBACK 필요, 동의 화면에서 카페 가입·글쓰기 항목 체크). API가 실패하면 자동으로 바꾸지 않고 멈추며, “브라우저로 진행”이라고 답하면 브라우저로 올립니다. API로는 글 수정·삭제가 되지 않습니다. 처음 한 번은 로그인 창 열기에서 직접 로그인해 주세요. 로그인을 마치면 창이 저절로 닫히고, 그다음부터는 AI가 알아서 로그인 상태를 씁니다. 로그인 창은 직접 닫지 마세요. 여러 사이트 계정을 미리 적어 두려면 작업 공간의 보관함/계정.env 파일을 씁니다(Git에 올라가지 않고 AI 직원은 읽지 못합니다).
  • 계속 지켜보는 업무(예: “새 자료가 올라오면 계속 정리해줘”)는 업무 카드에 오늘 쓴 AI 사용량이 보이고, 평소보다 크게 많이 쓰면 사용량 이상 알림이 뜹니다.
  • 내역 초기화: 끝난 업무·실행 기록을 정리합니다. 결과 파일과 계정은 지워지지 않습니다. 비서실장에게 “작업 내역 지워줘”라고 말해도 바로 처리합니다. 답변을 기다리는 업무는 남습니다. 그 대화에 “이 업무 끝내줘”라고 쓰면 끝나고 지울 수 있습니다.
6

AI 모델 권장 설정

업무가 너무 오래 걸리면 먼저 입력창 옆의 제공자·모델·effort를 확인하세요. effort는 AI가 얼마나 깊이 생각할지 정하는 값으로, 높을수록 오래 걸리고 사용량도 늘어납니다.

  • 평소 조사·자료 수집·글 초안: Claude · sonnet · high(Codex도 쓴다면 처음 설정값인 Codex · gpt-6.1-sol · high) Codex · gpt-6.1-sol · high(처음 설정값)
  • 외부에 제출하는 문서·숫자가 중요한 분석: Claude · opus · high(Codex도 쓴다면 Codex · gpt-6.1-sol · max) Codex · gpt-6.1-sol · max
  • 직원 모델은 조직 탭의 부서·직원 설정에서 고릅니다. 일반 실무와 자료 수집은 sonnet, 복잡한 기획·최종 취합은 opus, 대량 페이지 분류는 haiku를 권장합니다.
  • 계획은 Claude를 쓸 수 있으면 자동으로 Claude Opus · high가 맡으므로 따로 고르지 않습니다.
왜 달라지나요입력창 옆 설정은 최종 검토에 쓰입니다. 실제 기록에서 검토 1회는 Codex max가 약 4분 안팎, Claude Sonnet이 16~33초였습니다. Codex 검토는 원문을 검색해 대조할 수 있고, Claude 검토에는 웹 도구가 없습니다. 측정 건수가 적고 업무도 달라 참고용이며, 결과 품질 차이는 아직 측정하지 않았습니다. 그래서 중요한 문서는 더 높은 설정을 권장합니다.
  • 선택은 저장되어 다음 지시에도 그대로 쓰입니다. 중요한 업무에 맞춰 올렸다면 끝난 뒤 되돌려 주세요.
  • 단계 사이의 진행 점검은 속도를 위해 자동으로 가벼운 모델이 맡습니다.

8. 제휴 메일 보내기: 20통씩, 파일 첨부까지

조사한 업체·대학에 업체별로 따로 메일을 보내는 업무입니다. 대량 발송을 막으려고 한 번에 20통까지만 보내고, 지시문에 적은 파일을 모든 메일에 붙일 수 있습니다.

전체 흐름

지시하기→ 첨부 파일 확인→ 조사·업체별 문안→ 비서실장 검토→ “실행할까요?”→ 20통 발송→ “남은 메일 발송할까요?”→ 보고서
  • 첨부 파일에 문제가 있으면(못 찾음·같은 이름 여러 개) 조사를 시작하기 전에 먼저 묻습니다. 조사를 다 한 뒤 첨부 때문에 멈추지 않습니다.
  • 메일은 업체마다 따로 보냅니다. 받는 사람끼리 서로의 주소를 볼 수 없습니다.
  • 연락처를 확인하지 못한 업체에는 보내지 않고 보고서의 확인 필요에 이유를 적습니다.
1

준비하기 (처음 한 번)

  • 계정 연결에서 네이버웍스 메일 계정을 추가하고 로그인 창 열기로 직접 한 번 로그인합니다. 그다음부터는 AI가 로그인 상태를 씁니다.
  • 보낼 파일(제안서·회사소개서 등)은 작업 공간의 보관함 폴더에 넣어 두면 가장 확실합니다. 다운로드·문서·데스크톱 폴더에 있어도 찾습니다.
  • 처음에는 내 메일 주소로 시험 메일 1통을 보내 첨부가 잘 붙는지 받은 메일함에서 확인해 보세요.
내 주소 me@회사.com 으로 제휴제안서.pdf 첨부해서 시험 메일 1통 보내줘

질문에 답하기

파일을 못 찾았을 때

- "회사소개서.pdf": 작업 공간(보관함 포함)·다운로드·문서·데스크톱에서 파일을 찾지 못했습니다.

또는 파일을 보관함에 넣은 뒤 “이어서 재개”라고 답합니다. 파일 이름의 오타도 확인해 보세요.

진행

20통을 보낸 뒤

메일 20통을 보냈습니다. 남은 메일이 5통 있습니다. 다음 5통을 이어서 보낼까요? 1. 받는사람 next@example.com · 제목: 제휴 제안드립니다 …
진행

“진행”이면 다음 20통(남은 게 적으면 그만큼)을 보냅니다. 이미 보낸 곳에는 다시 보내지 않고, 조사·문안도 다시 만들지 않습니다. 100곳이면 20통마다 4번 더 묻습니다. “하지 마”면 남은 메일은 보내지 않고 보고서에 남깁니다.

4

결과 확인하기

  • 완료 창의 비서실장 보고서 맨 아래 외부 작업 결과에 보낸 메일마다 받는사람·제목과 발송 확인 여부가 나옵니다.
  • 확인 필요에는 연락처를 못 찾은 업체, “하지 마”로 보내지 않은 메일, 예약 업무에서 20통을 넘어 보내지 않은 메일이 적힙니다.
  • 보낸 곳 목록은 구글 시트 같은 관리 목록에 옮겨 두세요. 새 업무로 다시 지시하면 이전 발송 기록이 이어지지 않아 같은 곳에 또 보낼 수 있습니다. 다시 보낼 때는 “목록에 있는 곳은 빼고”처럼 적어 주세요.

첨부할 수 없는 파일

  • 보관함/계정.env 같은 계정 파일, 계정 저장 폴더
  • 숨김 폴더·숨김 파일(이름이 점(.)으로 시작)
  • .env·인증서·키 파일(.pem, .key, id_rsa 등)
  • 50MB를 넘는 파일. 회사 메일 첨부 한도가 더 작으면 메일 화면에서 막히고 AI가 확인을 요청합니다.
  • 지시문에 적지 않은 파일. AI가 알아서 다른 파일을 붙이지 못합니다.

20통 규칙

  • 메일은 한 번에 20통까지. 받는 사람 기준으로 셉니다.
  • “끝까지 자동으로”라고 맡겨도 20통마다 다시 묻습니다.
  • 예약·계속 지켜보는 업무처럼 내가 화면에 없는 업무는 묻지 않고 그 회차에 20통만 보냅니다. 나머지는 보고서에 남깁니다.
  • 첨부 파일이 빠진 메일은 보내지 않습니다.
macOS처음 다운로드·문서·데스크톱 폴더에서 파일을 찾을 때 “폴더에 접근하려고 합니다” 창이 뜰 수 있습니다. 허용을 누르세요. 거부하면 그 폴더는 건너뛰므로 파일을 보관함에 넣어 두면 됩니다.
주의영리 목적의 광고성 메일은 받는 사람의 사전 동의가 필요할 수 있습니다(정보통신망법). 웹사이트에서 이메일 주소를 자동으로 모으는 것도 금지돼 있습니다. 공개된 제휴 문의 창구로만 업체당 1통 보내고, 본문에 보내는 사람 정보와 수신 거부 방법을 넣도록 지시하세요. 법적 판단이 필요하면 전문가에게 확인하세요.

11. 꼭 지켜 주세요

  • 비밀번호·카드번호·인증번호를 AI 대화창이나 업무 지시에 적지 마세요. 바깥 사이트 계정은 계정 연결 창이나 보관함/계정.env 파일에만 둡니다.
  • 메일 발송·글 게시처럼 밖으로 나가는 일은 내가 지시한 경우에만 실행되고, “끝까지 자동으로”라고 맡기지 않았으면 올리기 직전에 한 번 확인합니다. 지시하지 않으면 초안까지만 만듭니다. 송금·결제·세금 신고·계약·삭제·탈퇴는 AI가 하지 않습니다.
  • AI가 만든 숫자와 사실은 중요한 곳에 쓰기 전에 꼭 원본과 확인하세요. 결과 보고서의 “확인 필요” 항목을 먼저 봅니다.
  • 모든 작업은 내 Claude·ChatGPT 계정 사용량을 씁니다. 큰 업무를 한꺼번에 많이 맡기면 한도가 빨리 찰 수 있습니다.
  • 회사 데이터(부서·직원·결과 파일)는 내 컴퓨터의 AIOffice 폴더에 있습니다. 컴퓨터를 바꾸기 전에는 회사 설정 → 회사 구성 내보내기로 백업하세요.

12. 막혔을 때

대부분은 터미널의 AI에게 화면에 보이는 그대로 말하면 해결됩니다.

claude나 codex를 입력했더니 “찾을 수 없다(command not found)”고 나와요

터미널 창을 닫고 새로 연 뒤 다시 입력합니다. 그래도 안 되면 3-2단계의 설치 줄을 한 번 더 붙여 넣습니다.

AI가 자꾸 “실행해도 될까요?”라고 물어봐요

AI가 내 컴퓨터에서 무언가를 실행하기 전에 허락을 받는 정상 동작입니다. 설명을 읽고 괜찮으면 Yes를 고릅니다. 모르겠으면 “이거 뭐 하는 거야?”라고 물어보세요.

브라우저에 대시보드가 안 열려요

주소창에 http://127.0.0.1:4777 을 직접 입력합니다. 그래도 안 되면 AI에게 “서버 상태 확인해줘”라고 말합니다.

화면 위에 “Claude/Codex가 설치되지 않았습니다”라고 떠요

둘 중 하나만 쓰기로 했다면 안 쓰는 쪽 안내는 무시해도 됩니다. Claude만 쓰면 상단 검토 선택을 Claude로 바꿉니다. Codex만 쓰면 Codex가 계획·실무·검토를 모두 맡습니다. 나중에 다른 쪽도 쓰고 싶으면 AI에게 “Codex도 설치해줘”(또는 “Claude도 설치해줘”)라고 말합니다.

업무가 멈춘 것 같아요

오른쪽 업무 · 실행 목록에서 상태를 봅니다. “답변 필요”라면 답을 적어 주세요. 멈췄다면 그 실행을 중지한 뒤 대화창에 “이어서 재개”라고 답하면 끝난 단계는 건너뛰고 이어서 합니다.

노트북을 끄기 전에는 지시창에 “하던 작업 멈추고 정리해 둬, 다음에 이어서 하자”라고 쓰세요. 모든 업무를 멈추고 업무 폴더마다 정리 노트(pause-note.md)를 남깁니다. 다음에 “이어서 해줘”라고 쓰면 한 번에 다시 시작합니다.

“사용량 한도에 도달했습니다”라고 나와요

내 Claude 또는 ChatGPT 구독의 사용량을 다 쓴 상태입니다. 안내된 시간이 지나면 다시 쓸 수 있습니다. 둘 다 있다면 다른 쪽 AI로 바꿔 써도 됩니다.

그 밖의 문제

화면에 나온 오류 문장을 그대로 복사해서 AI에게 붙여 넣고 “이거 해결해줘”라고 말합니다.
